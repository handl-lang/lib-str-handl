# Reference

## Public API

| item | what it is |
|---|---|
| `length`, `char_at`, `slice`, `concat`, `repeat` | core access and construction |
| `trim`/`trim_start`/`trim_end`/`trim_matches`, `strip_prefix`/`strip_suffix` | edge handling |
| `split`, `split_at`, `split_whitespace`, `lines`, `join` | splitting and joining |
| `find`, `rfind`, `contains`, `starts_with`, `ends_with`, `count`, `replace`, `replace_first` | search |
| `upper`, `lower`, `camel_case`, `snake_case`, `kebab_case`, `pascal_case`, `title_case`, `slugify` | case and naming |
| `pad_left`, `pad_right`, `truncate`, `word_wrap` | presentation |
| `levenshtein`, `similarity` | distance |

## Crate

| crate | role |
|---|---|
| `str-handl` | string library — pure handl |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # hnl test src/ (each module ships `*.test.hnl`)
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
